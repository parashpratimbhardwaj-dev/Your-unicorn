# Your Unicorn

An AI-powered business name and domain finder that helps entrepreneurs discover unique brand names, available domains, taglines, logo ideas, and complete brand identities in seconds.

## Features

- AI Business Name Generator
- Domain Name Suggestions
- Brand Identity Creation
- Tagline Generator
- Logo Concept Ideas
- Modern Chat-Based Interface
- Dark Mode Design
- Fast and Responsive Experience

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (Latest LTS Version)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone <your-repository-url>
```

2. Navigate to the project directory

```bash
cd your-unicorn
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env.local` file in the root directory and add your Gemini API key

```env
GEMINI_API_KEY=your_api_key_here
```

5. Start the development server

```bash
npm run dev
```

6. Open your browser and visit

```text
http://localhost:3000
```

## Build for Production

```bash
npm run build
```

## Start Production Server

```bash
npm start
```
